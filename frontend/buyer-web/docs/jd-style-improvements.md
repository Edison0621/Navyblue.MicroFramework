## 📝 使用说明

### 运行项目
```bash
cd frontend/buyer-web
npm install
npm run dev
```

### 环境变量
```bash
VITE_GATEWAY_BASE_URL=http://localhost:5006
```

### 质量检查
```bash
npm run lint
npm run test
npm run build
```
