# Platform Buyer Admin

Platform-side buyer management console.

## Run

```bash
npm install
npm run dev
```

## Environment variable

```bash
VITE_GATEWAY_BASE_URL=http://localhost:5006
```

## Implemented modules

- buyer list and search
- buyer detail panel
- tags update
- blacklist toggle
- level adjustment
- close request approval queue
- platform shell and route guard
- merchant governance entry
- category tree management entry
- product audit queue
- order arbitration entry
- marketing/finance/ticket/risk/system entries
